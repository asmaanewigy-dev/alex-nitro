# ALEX NITRO · نيترو إسكندرية

لعبة سباق عربيات في شوارع إسكندرية، بتشتغل في المتصفح وتتنزل على الموبايل زي أي أبلكيشن.

**العبها:** https://asmaanewigy-dev.github.io/alex-nitro/

- ٣٨ مرحلة: الكورنيش، جوه البلد، الطريق الصحراوي، الساحل الشمالي، ورشيد
- ٣٢ عربية، وكل عربية ليها تابلوه من جوه وصوت موتور خاص بيها
- دريفت، نيترو، نطّات ولفّة ٣٦٠ في الهوا، وفتيس D و R
- كاسيت في العربية بتلاوات القرآن الكريم

## تنزلها على الموبايل
- **أندرويد:** افتح اللينك في Chrome ودوس «نزّل اللعبة على موبايلك»، أو من قايمة ⋮ اختار Install app.
- **آيفون:** افتح اللينك في Safari، دوس زرار المشاركة، واختار Add to Home Screen.
